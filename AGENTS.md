# Die Lichtung Website

- Auf Deutsch kommunizieren.
- Nuxt 4 mit Vue 3 und TypeScript verwenden.
- Die gestalterische Grundlage ist das vom Nutzer bereitgestellte fertige Handout. Dunkles Waldgrün, warmes Papierweiß, Serifentypografie, botanische Elemente und die Lichtungslandschaft beibehalten.
- Alle verwendeten Assets lokal unter `public/` ablegen; keine externen Font- oder Bild-URLs im Seitenlayout verwenden.
- Inhalte und Herkunft: `references/ASSETS.md`, `references/handout-canva.png`, `app/app.vue`.
- Namen: Stefanie Schwartz und Maik Schneekönig. Kontakt: ankommen@lichtung.be.
- Das Projekt ist eine entstehende Gemeinschaft, kein bereits bestehender Wohnort. Keine Grundstücke, Termine, Angebote oder Rechtsangaben erfinden.
- Bei Änderungen `npm run typecheck` und `npm run build` ausführen. Layout bei 390 und 1440 Pixeln im Browser prüfen.
